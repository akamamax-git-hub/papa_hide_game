# KNOWN ISSUES / 再発防止リスト

## 1. 外部CDN依存
Phaser CDNがブロックされると画面だけ表示され、ボタン/Tween/アニメーションが全停止した。
→ Standalone HTMLを優先。

## 2. パパ頭部クリップ
複数回再発。
→ 画像そのものに上部透明余白、CSS/container overflowも確認。

## 3. 猫画像の不要文字
生成画像由来の文字断片が残った。
→ 透過アセットを目視確認。

## 4. アイテムが使えなくなる
新聞をBAGへ入れた後に選択/使用できない版が発生。
→ pickup / inventory / selectedItem / useOnTarget を分離してE2E。

## 5. 動くキャラのクリック判定
Tween対象自身をHit Areaにしたためクリックを取りこぼした。
→ 見た目と固定Hit Areaを分離。

## 6. Stage間タイマー競合
前StageのCLEAR/FAILED遅延処理が次Stageに漏れる可能性があった。
→ runTokenで古いタイマーを無効化。

## 7. 家具の浮遊
背景と家具のパース/接地基準が一致せず浮いて見えた。
→ bottom-center anchor、ground line、接地影、z-indexをデータ化。

## 8. 不自然な部屋配置
TVがドアを塞ぐなど、生活空間として成立しない配置があった。
→ ドア前動線を空ける。大型家具は背景設計段階で固定。

## 9. 偽アニメーション
1枚絵の上下移動だけで歩行/動作を表現して不自然だった。
→ ポーズ/フレーム差分を実制作。

## 10. 過剰なSVG/CSS家具
ユーザーが「クオリティが低い」と明確に拒否。
→ 家具/小物は画像アセットを使う。
