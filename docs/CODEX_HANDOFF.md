# CODEX HANDOFF — パパにゲーム隠された

## 1. プロジェクト概要
ユーザーとChatGPTで反復開発してきた、オリジナルの家庭内探索・脱出ゲーム。
主人公の少年が、パパに隠されたゲーム機を家の中で探す。アイテム取得、ドラッグ/クリック使用、NPC誘導、環境変化、罠、警戒度、シュールな展開を組み合わせ、全50Stageで構成する。

ゲームの核は「見つける / 取る / 使う / 回避する」。
本家作品の具体的なステージをコピーせず、一般的な脱出ゲーム文法のみ参考にする。

## 2. コアキャラクター
- 息子（主人公）: 約10歳、短い黒髪、青Tシャツ、濃色ショーツ、白ソックス。
- パパ: 黒髪、眼鏡、白い半袖ポロ、グレーのパンツ。
- ママ: 茶色ポニーテール、ピンク系トップス、白エプロン、グレーパンツ。
- 白猫。
- ゲーム機: 青/赤の左右コントローラを持つ架空の携帯ゲーム機。特定メーカー製品そのものには寄せすぎない。

後半NPC:
ママ、妹、おじいちゃん、おばあちゃん、宅配員、郵便屋さん、修理屋さん、となりの子、カラス、犬、ロボット掃除機、宅配ロボット。
NPCは単なる装飾ではなく、交換・誘導・協力・妨害・時間イベントの役割を持つ。

## 3. アート方針
当初の紙クラフト調より、現在は「明るいアニメ/絵本調・ややリアルな家庭空間」に寄せている。

基本色の原点:
- 背景クリーム #FFF7E8
- 文字/輪郭ネイビー #24324A
- 主人公コーラル #E76F51
- パパ ティール #2E7D78
- ママ バイオレット #7B61A8

重要なのは色コードより、以下の品質:
- 家具の接地感
- 1部屋1パース
- ドア動線が自然
- キャラ頭部/手足/尻尾が切れない
- 生成画像内の不要文字を除去
- キャラのポーズ差分を十分に用意し、静止画を上下に揺らすだけの「偽アニメーション」にしない

## 6. 現在の実装原則
- Standalone HTML。
- 外部CDN依存を避ける。
- Stageごとのロジックを個別JSで書かず、Stage JSONを共通エンジンが処理。
- Stage状態: PLAYING / CLEAR / FAILED。
- Inventoryあり。選択アイテムあり。
- パパ警戒度あり。
- CLEAR/FAILEDの遅延処理はrunTokenで古いStageからの漏れを防ぐ。
- BGM/SE/音声合成を使用。

## 7. 重要UX
- 新聞→BAG→選択→パパに使う、のような一連の物理的納得感を重視。
- アイテム使用はクリックとドラッグの両方を許容する方向。
- ヒント H、BGM M、デバッグ D のショートカットを過去版で使用。
- CLEARは強い達成演出＋元気な「ヤァリー！」。

## 9. ユーザーの品質要求
ユーザーは、次の問題を繰り返し強く指摘している。
- キャラクターデザインが元画像と違う
- クオリティが低い
- スマホ/HTMLで動かない
- ゲーム機デザインが違う
- パパ/猫の頭部が切れる
- SVG/CSS家具が安っぽい
- アイテムが使えなくなる
- ボタンが反応しない
- アニメーションが実質できていない
- 家具が空中に浮く
- TVがドアを塞ぐなど部屋配置が不自然

したがって、Codexは「動いたから完了」とせず、実ブラウザ動作と視覚品質を両方確認すること。
