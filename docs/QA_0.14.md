# Ver0.14.0 検証記録

## 対応した指摘

1. 新聞を渡す時の子供とパパの重なり: 左へ手を出す受け取り素材、実際の手への接触、胴体の重なりを避ける立ち位置へ変更。
2. TVの表示角度: 閉・開状態それぞれのガラス面の四隅を採寸し、同じ四角形へ画面を描画。
3. 壁時計: 窓や床近くに重なる配置から、右の壁面へ移動。高い時計裏の電池にも実在する踏み台を使用。
4. 踏み台・椅子・脚立: 床の配置と遠近を統一。足場の面と、画像から読んだ足先の接触点を対応させる。体の中心だけの判定を廃止。
5. 前後移動の縮尺: 人物・家具・道具を同じ奥行き係数で描画。持って伸ばす物は接触面の奥行きで大きさを確定し、先端・持ち手を合わせる。
6. 土足・裸足: 全人型キャラクターの室内用靴下と、屋外用のパパの靴を制作。玄関の段差を基準に切替。パパの初期位置を上がり框から室内床へ移動。
7. 思考する探索: 正解の常時表示と全体の答えの漏出を外し、調べた対象ごとの情報をメモに残す。前提を満たせば別順の取得・観察が可能。
8. BAGドラッグ: 実物・床・別のBAGアイテムへ使用。間違った道具・床へのドロップは進行や所持品を失わない。
9. 箱の謎: 実際にクリックした色の箱を扱う。正解色を選ぶ別の入力画面へ差し替えない。
10. 追加発見: 机に置いた新聞の描画順、傘・本・磁石の配置、網・トングの接触、カラスを追い払う失敗動作を修正。
