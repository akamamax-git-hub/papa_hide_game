# Ver0.13 検証記録

## 修正した問題

- 取得の接近先がアイテム本体でなく親家具の右端になっていた。描画された持ち手／操作点に手が接触してから、同一の物を所持状態に移す方式に変更。
- 最終手順でゲーム機を生成していた。全50Stageで開始時から収納内に同一個体を置き、実際に開いた場所から取り出す方式に変更。
- 収納内の物や置いた物が家具の裏に隠れた。親子関係・描画順と、操作後に次の対象を塞がない立ち位置を修正。
- スイッチ、星ボタン、暗証番号錠、インターホンなど、操作対象が絵に無かった。画像アセットと操作点を追加。
- 開閉で別の家具へ変わる、背景素材に鍵や箱が描き込まれる問題。対応する開閉素材と空の収納・土・氷を制作し、操作する物を別の実体に統一。
- 時計裏の電池、ロボットの収納、上段収納、クッション、掃除機が押し出す鍵、網・トングなどの位置を修正。
- 傘・本・磁石を個別の物にし、並べ替えを描画。コーヒーはカップを置き、ポットを持って注いで戻す動作を実装。
- Stage13は道具の入手でゲーム機の収納まで開いてしまうため、洗面台内の鍵付き箱へ分離。Stage14はメモを閉じたかごのふたへ配置し、後続手順を成立させた。

自動テストの通過だけで主観的な自然さや面白さを保証しません。動作は2Dの描画済みポーズと座標移動の組み合わせです。音声の確認はデコード・再生状態であり、実スピーカーでの聴感評価ではありません。GitHub Pages上の配信結果は、この環境のローカルブラウザ検証とは別です。
