# Ver.0.11 — 開発記録

## 実装の考え方

引継ぎ版のシナリオ・音声・少年/パパ/猫を維持し、Stage21〜30用のデータと描画処理を `Chapter3` に分離しました。
シナリオの手順に対応するターゲット、画像状態、取得物、使用条件、道具保持は宣言データです。
共通のゲーム状態・アイテム状態を通して、行動ボタンと部屋内のクリック／ドラッグが同じ進行処理を呼びます。

## 今回見つけて修正した問題

- キッチン背景が洗面所画像だった。
- 遅延更新前に同じ正解ボタンを連打すると複数手順が進み得た。
- メニュー移動でStage状態と遅延コールバックが残り得た。
- 新しい道具使用の実装で懐中電灯が消費され、次の使用手順を満たせなかった。
- 猫と箱のマーカーが重なって実クリックできなかった。
- 妹のポーズ名とプリン小物名が衝突していた。
- 生成NPCシートの行高が均等でなく、等分表示では頭部が切れた。

## 検証方法

- `node tests/browser.cjs`: 全50Stageを正解ルート→CLEAR、失敗ルート→FAILED、結果画面からRetry。現在の実行結果は `test-results/regression.json`。
- `node tests/chapter3.cjs`: Stage21〜30を部屋内マーカーだけでクリア。BAG選択・ドラッグ、必要アイテム未選択、連打、リトライ・メニュー移動後のタイマー、音声デコード・切替、ロード後オフライン操作。結果は `test-results/chapter3.json`。
- 画面キャプチャ: `test-results/stage-21.png`〜`stage-30.png`。

クラウドのChromiumは `file://` ナビゲーションを管理ポリシーで拒否したため、ローカルサーバーでの起動とロード後オフライン動作で検証しています。ファイルを直接開く方法の実ブラウザ検証は未実施です。
音声ファイルのデコード・再生状態は機械的に検証しますが、実スピーカーでの聴感確認はできません。

拡大ビュー中心の状態表現を部屋全体の家具差分へ展開し、Stage22/29の数値入力、Stage26の並べ替え、NPCの受け渡し・着席アニメーションを強化。その後Stage31〜40へ進みます。
