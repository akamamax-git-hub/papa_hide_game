# 現在の状態 — Ver0.13.1

全50Stageを、描画された物の持ち手・操作点と手の位置を合わせる共通処理に修正しました。

- `src/world.js`: 部屋・家具・人物・物の共通座標、親子・所持状態、透過ピクセルのクリック判定。
- `src/contacts.js`: 接近、手の接触、取得、受け渡し、配置、道具の先端、踏み台、部屋移動。
- `scripts/contact_profiles.py`: 全Stageの実在する収納元、操作点、持ち手、個別の並べ替え対象。
- `scenario/storyboards.json`: 全50Stage・269動作。Stage45にも最後の取得手順を明示。
- `assets/world/`: 手を伸ばすポーズ、見えるスイッチ・暗証番号錠・星ボタン、開閉が対応する家具、時計の背面、宅配ロボットの開いた収納、個別の傘・本など。

ゲーム機はStage初期化時に各収納内へ配置します。最終手順で新しく生成せず、同じ個体を実際の収納位置から手に移します。家具の右端などを拾う場所の代用にしません。置いた物は載っている家具に所属させ、家具の裏へ消える描画順も修正しました。

`npm start` でローカル配信。`npm test` は全50Stage・269動作の実物クリック、収納元と個体の維持、接触誤差、53失敗ルートとRetry、BAG、タイマー、100件のPC表示、音声のデコードと切替を検証します。今回の実行は全件通過しました。最終画像確認で見つかった収納棚の種類、読書中の椅子、食べ終わったおやつ、箱の色、会話・待機の動作も修正しています。

詳細と検証範囲は `QA_0.13.md`、数値は `VALIDATION_0.13.json` を参照してください。旧版の検証は現行版の結果として扱いません。公開サイトの稼働とローカル検証は別であり、公開はmainへのpush後のGitHub Pagesワークフローによります。
