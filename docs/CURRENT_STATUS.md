# 現在の状態 — Ver0.12

全50Stageに共通する物理的な描画・所持品・動作の実装へ置き換えました。旧Ver0.11の「選択肢だけ進めればCLEARになる」方式と、Stage21〜30だけにあった拡大ビューは現行ビルドでは使用しません。

- `src/world.js`: 同一座標の背景・家具・人物・物、アニメーション、受け渡し、物理状態、前提条件。
- `src/game.js`: タイトル・ステージ選択・UI・音声・結果とパズル入力。
- `scenario/storyboards.json`: 全50Stage、268手順、実体・担当人物・使用道具・結果・部屋遷移。
- `scenario/sprite-catalog.json`: 画像の描画範囲とワールド内の寸法。通常ビルドでは画像加工しません。
- `assets/world/`: 新しい部屋・家具・人物のポーズ・小物・開閉状態。

不足していた道具の入手元と部屋移動を追加しました。前提アイテムがない、または使用アイテムが未選択のままでは進行しません。元の50Stage企画表は保存し、追加した準備手順はストーリーボードに明示しています。

`npm start` で配信、`npm test` で実ブラウザ検証。`#stage=23` のようなURLで各Stageへ直接入れます。プッシュ後の公開はGitHub Pagesのワークフローを使用します。

検証方法・実行結果・限界は `QA_0.12.md` と `VALIDATION_0.12.json` を参照してください。過去版の通過記録は現行版の通過記録ではありません。
