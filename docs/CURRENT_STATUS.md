# 現在の状態 — Ver0.14.2

「部屋を準備しています」で画面全体を止める処理を廃止しました。人物・家具・アイテムの表示済みの画像から操作できます。背景の未完了・失敗、未使用のポーズや隠れた物の読み込みは、入室と操作を止めません。

`src/assets.js` は最初に見えている物と現在の人物フレームだけ準備し、背景は独立した低優先度処理へ分離。`src/contacts.js` は歩行・手を伸ばす動作に使う実際のポーズを直前に準備します。画像はフレームごとの可逆WebPへ分け、見える画素・アルファ・描画領域の寸法を検証しています。

全画面マスクの代わりに小さな状態表示を使います。未読込の画像ではクリック判定を待たず、表示済みの物を拾えます。画像の再試行はアイテムと進行を保持。動作中の画像失敗では同じゲーム機・実体を維持して開始前の状態へ戻し、再操作できます。タイムアウトは8秒です。

`npm run build` は公開用 `dist/web/` と単体オフライン版 `dist/offline/papa-hide-game.html` を生成。公開は `dist/web/` のみ。外部CDN・起動時の全音声取得はありません。検証は `QA_0.14.2.md`、`VALIDATION_0.14.2.json`、`test-results/v0142/` を参照。

以下のVer0.14.0の描画・パズル改良も維持しています。

PC向け全50Stage・272動作。人物・家具・道具の遠近、新聞の手渡し、TVの画面、壁時計と足場、履き物、探索UIを改良した版です。

- `src/scene.js`: 共通の奥行き縮尺、家具の足元、床の経路、足場の面と実画像の足先、玄関の内外判定。
- `src/world.js`: 実体・所持状態・透過ピクセル判定・描画順。TVは素材に採寸した画面の四隅へ表示。
- `src/contacts.js`: 手・道具の接触、取得、受け渡し、配置、上り下り、移動。新聞は新しいパパの受け取りポーズへ渡し、子供の胴体との重なりを避ける。
- `src/game.js`: 通常は正解手順を非表示。調べて分かった情報をメモへ記録し、任意のヒントから明示的に手順表示へ切り替えられる。
- `scripts/puzzle_design.py`: 操作の前提関係、物ごとの観察情報、床への配置範囲。前提を満たす独立した取得や観察は別順でも進められる。
- `scripts/feet_profiles.py`: 元画像の不透明な足先を読み取り、足場の接触点を記録。画像を加工しない。
- 新素材: 室内用の靴下、屋外のパパの靴、パパの受け取り姿、二段の踏み台。

壁時計は窓と重ならない壁面へ移動。Stage2には踏み台を取る・置く・上がる3動作を追加しました。踏み台はBAGから床へドラッグし、実際のドロップ座標へ置きます。配置プレビューが表示され、届かない位置ではアイテムを失いません。足場は体の中心だけでなく、描かれた足先が天板・座面・脚立の段にかかることを検証します。

BAG内の道具同士の組み合わせ、誤った道具による進行の防止、床のクリック移動を追加。Stage41・44では画面内の箱を直接選択し、選んだ箱と実際に開く箱を一致させました。Stage48の新聞はテーブルに所属させ、裏へ隠れる描画順を修正しています。

玄関は上がり框の室内側と土間を分けて履き物を切り替えます。パパの初期位置も段差上から室内の床へ移しました。庭・屋外では靴、室内では靴下の描画を使用します。

ゲーム機は開始時から実際の収納内にある同一個体を取得します。BGM・SE・ヤァリー、Standalone HTML、run tokenを維持しています。
